## 1. 为什么不能加总成一个分数

三组评测的**失败模式完全不同**：

| 组 | 走哪条路 | 失败长什么样 | 指标 |
|---|---|---|---|
| 结构化（60） | 抽参数 → 查表 → 模板 | 数字算错（赔钱事故） | 数值正确率 |
| 检索（49） | 向量检索 + 重排 | 没检索到对的材料 | Recall@5 / MRR |
| 答案（60） | 检索 + 大模型生成 | 该答没答 / 该拒没拒 | 状态正确率 / 引用覆盖 |

把它们平均会让一个严重问题被另一个好看的数字掩盖。
所以 `eval_all.py` 只并列展示，从不求和。

## 3. 本轮修的问题

### 3.1 评测标签错了，不是系统错了

上一轮 `after_sales` 只有 78%，看着像系统退化。逐条查下去，**7 条里有 3 条是标签错**：

题面是"客户要一块 3000×3000 的板，能做吗？"——**没给厚度**。
系统正确地追问了 "What thickness do you need?"，
但标签写的是 `expected_state=ok`（必须作答），于是"正确追问"被记成"答错"。

修法：出题时对每题跑一次槽位抽取，提到尺寸但不全的，标签改为 `need_slot`。
改完 `after_sales` 回到 **100%**。

**教训：分数掉了先看样本，别先改系统。** 这已经是第二次了（M4 那次也是评测集的问题）。

### 3.2 子串匹配踩了两次坑

路由靠关键词判断"是不是在问尺寸"，最直觉的写法 `hint in text` 是错的：

| 写法 | 误判 | 后果 |
|---|---|---|
| `"tall" in text` | `install` 里含 `tall` | "能上门安装吗" → 被当成尺寸问题去追问 |
| `\bpane` | 能匹配 `panels` | "能把两块拼成一块吗" → 被当成要报价 |

最终方案：**两端词边界 + 只放行词形后缀**（s/es/er/ed/est）：

```python
rf"\b(?:{'|'.join(hints)})(?:s|es|er|ed|est)?\b"
```

这样 `thick` 能匹配 `thicker`，但 `pane` 不会匹配 `panels`。
两条都用单测锁住了（`tests/test_router.py`）。

### 3.3 尺寸提示词不能单独用

第一版只要出现 `big`/`panel` 就去追问，结果误伤政策类问题：

```
Customer insists on one piece. Can we join two panels invisibly?
→ 被追问"What thickness, width and height do you need?"   ✗
```

这句话问的是**能不能拼**，文档里有答案。加了第二道判据：只有同时出现在
"能不能做 / 多少钱 / 多久"的语境里，尺寸提示词才意味着"缺参数"。

### 3.4 引用覆盖率的定义错了

原来分母是所有题，于是"正确追问"（本来就不该有出处）被算成"缺引用"。
改为**只统计实际给出答案的题**，覆盖率从 82% 变成 100%。

指标定义错了，比数字难看更危险——它会让人去"修复"一个不存在的问题。

## 4. 已知局限（不掩饰）

| # | 局限 | 影响 | 为什么不现在修 |
|---|---|---|---|
| 1 | 结构化类的 ground truth 与查询表同源 | 是"自证"，验证链路而非独立验证数据 | 要独立验证得人工核对 60 行原始表格 |
| 2 | "要点命中"是启发式 | 不能当准确率对外说 | 精确判分需 LLM 评委或人工，成本高 |
| 3 | 1 条负面样例（"能上门安装吗"）被答而非拒 | 答案内容其实是"我们资料里没有安装信息，需要同事确认"，方向对但状态标成了 answer | 修它要改提示词并重跑 51 次生成，收益极小 |
| 4 | 意图分类器（M4c）未做 | 尺寸类已由槽位分流，暂不需要 | 需要约 800 条标注数据，一次性 token 成本 |

## 5. 面试怎么讲

> "评测我拆成三组，因为它们的失败模式不一样：查表是数字算错、检索是没找对材料、
> 生成是该拒没拒。加总成一个分会互相掩盖。
>
> 中间有两次分数掉了，我都是先去看样本，结果两次都是**评测集的问题**不是系统的问题：
> 一次是同一厚度下平板和异形生成了文字相同的题目，一次是'该追问'被标成了'该作答'。
> 这让我养成一个习惯——分数掉了先怀疑尺子。
>
> 还踩了两次子串匹配的坑：`install` 里含 `tall`，`\bpane` 能匹配 `panels`。
> 最后改成两端词边界加词形后缀，两条都写了单测锁住。
>
> 最终：结构化 60 题 100%、检索 Recall@5 88.7%（p95 247 毫秒）、
> 答案状态正确 98%、引用覆盖 100%，结构化那 60 题全程零 token。"
