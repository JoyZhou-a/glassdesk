## 5. 风险与不一致（必须处理）

| # | 问题 | 影响 | 处理方案 |
|---|---|---|---|
| R1 | 系统默认 Python 是 **3.14.7** | torch / transformers 在 3.14 上多半无 wheel，装不上或编译失败 | 项目 venv 固定 `--python 3.12`（uv 已有 3.12.14） |
| R2 | GPU 8 GB，已占用 2 GB，仅剩约 6 GB | bge-m3(fp16 ≈2.2G) + reranker(fp16 ≈2.2G) 同驻 ≈4.4G，余量小；批量入库时容易 OOM | 编码与重排**分时加载**（入库时只加载 embedder，查询时再加载 reranker）；或 reranker 降到 CPU + 减小候选数 |
| R3 | DeepSeek 请求 `deepseek-chat`，实际返回 **`deepseek-flash`** | 配置里写哪个模型名会影响行为与计费 | 配置中显式写 `deepseek-chat`，并在日志里记录实际返回的 model 字段 |
| R4 | 机器上 **没有 BERT 模型** | 意图分类无法训练 | 需从 ModelScope 下载英文底座（`distilbert-base-uncased` 或 `bert-base-uncased`），**不是 `bert-base-chinese`** |
| R5 | Milvus `utility.list_databases` 在 pymilvus 2.4 中不存在 | 脚本用错 API 会报错 | 统一用 `MilvusClient.list_databases()` |
| R6 | pymilvus < 2.5 依赖 `pkg_resources`，而新版 setuptools 已移除它 | `ModuleNotFoundError: No module named 'pkg_resources'` | requirements 中固定 `setuptools<80`，或改用 pymilvus ≥2.5 |
